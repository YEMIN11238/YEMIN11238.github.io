# 张俊豪的个人工作台

张俊豪的个人网站，使用 HTML、CSS 和原生 JavaScript，部署于 GitHub Pages。

- 关于、产品、工具与 Skill、记录、社交入口
- 终端启动、浅深色主题、键盘导航
- 手机布局、减少动画与无 JavaScript 内容降级

## 本地预览

```sh
python3 -m http.server 4211 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:4211/`。

项目文案和链接位于 `index.html`，样式位于 `styles.css`，导航交互位于 `app.js`。
## 展示内容

首页和作品集展示 AIPM Workbench、CinePilot、MioBot、Mosslume、百妖牌馆与麦麦点餐挑战。工具页展示麦麦老样子迁移助手、Glass UI、Pop 和 Wild Talker。旧概念站、横版动作实验和待办面板预览已撤出展示。

项目文案、筛选分类和数量直接写在 `index.html`，更新时需同步首页推荐、作品/工具卡片、启动终端、公开记录与计数。优先链接实际介绍、可玩页面和运行说明，保留 Demo、开发中等阶段说明。
