# 张俊豪的个人工作台

张俊豪的个人网站，使用 HTML、CSS 和原生 JavaScript，部署于 GitHub Pages。

- 关于、产品、工具与 Skill、记录、社交入口
- 终端启动、浅深色主题、键盘导航
- 手机布局、减少动画与无 JavaScript 内容降级

## 本地预览

```sh
python3 -m http.server 4211 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:4211/`。

项目文案和链接位于 `index.html`，样式位于 `styles.css`，导航交互位于 `app.js`。
截图来自各项目公开展示资源；上游与第三方素材的来源和许可见对应项目仓库。
